. Proje bir web projesi olduğundan hem web desktop hem de web mobile uyumlu olması gerekmektedir. Normalde veriler URL parse edilerek çekilecektir, ancak şu an test aşamasında sadece portfolios/oguzhan_ozdemir dokümanındaki verilerle çalışılacaktır.

UI dosyasında belirtilen kurallara uygun şekilde, Firebase'deki veriler kullanıcı arayüzünde gösterilecek ve ortaya etkileyici bir mobil geliştirici portföyü çıkarılması hedeflenmektedir.

Veri adresleri ve detayları için firebase_structure.md dosyasına bakınız.
Ayrıca kullanıcı arayüzüne dair tüm bileşen tanımı ve kurallar için portfolio_ui.md dosyasına bakınız.
